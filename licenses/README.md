# License and copyright texts

The port's GPL-3.0 license text is at [../LICENSE](../LICENSE). The original copy
at `eden/LICENSE` is preserved. The port's notices state GPL-3.0-or-later;
individual source and dependency notices remain in force.

`dependencies/` contains 159 original license, copying, notice, copyright, and
author texts collected from the inputs used for `0.5.54rc`. Their original
contents are retained. `MANIFEST.json` records SHA-256 hashes and sizes;
component directory names retain provenance.

See [../THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) for the component map
and [../SOURCES.md](../SOURCES.md) for source and build instructions. These texts
supplement the notices retained in vendored source directories; they do not
replace or relicense those components.

When changing a dependency, update its pin, source location, license/copyright
texts, notices, and release source-availability records together. A public
source fork remains subject to those licenses.
